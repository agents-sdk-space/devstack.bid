# เริ่มต้นใช้งาน · Getting started

หน้านี้พาคุณจาก "ยังไม่รู้จักแอป" ไปจนได้สคริปต์ตั้งค่าโปรเจกต์ที่รันได้จริงภายในไม่กี่นาที พร้อมอธิบายว่าทำไมแต่ละขั้นจึงออกแบบมาแบบนี้

## NVX Stack Builder คืออะไร

เวลาเริ่มโปรเจกต์ใหม่ นักพัฒนามักต้องค้นคำสั่งจากหลายแหล่ง เช่น ติดตั้ง Node ผ่าน nvm, สร้างแอปด้วย `create-next-app`, ติดตั้ง dependency, เพิ่ม ESLint/Vitest/Docker แล้วยังต้องจำว่าคำสั่งไหนต้องรันก่อนหลัง และบน Windows ต้องเขียนต่างกันอย่างไร NVX Stack Builder รวบรวมสิ่งเหล่านี้เป็น **Stack Template** คือชุดขั้นตอนที่เรียงลำดับแล้ว ตัดคำสั่งซ้ำแล้ว แต่ละขั้นมีคำอธิบายไทย/อังกฤษ คำสั่งแบบ POSIX และ PowerShell หมายเหตุตามระบบปฏิบัติการ ผลลัพธ์ที่คาดหวัง และคำสั่งตรวจสอบ (verify)

แนวคิดสำคัญคือ **แอปไม่รันคำสั่งแทนคุณ** ทุกอย่างเป็นข้อความที่คุณอ่าน ตรวจ แล้วรันเองบนเครื่อง เหตุผลคือคำสั่งตั้งค่าโปรเจกต์แตะไฟล์ระบบและติดตั้งซอฟต์แวร์ การให้มนุษย์ตรวจก่อนเสมอปลอดภัยกว่าและโปร่งใสกว่า (ดู [Safety model](../concepts/safety-model.md))

## สามเส้นทางเริ่มต้น

1. **เลือกเทมเพลตเอง** ไปที่หน้า `/templates` ค้นหาด้วยคำ เช่น `python`, `game`, `react` หรือกรองตามหมวด แล้วกดเปิดดูขั้นตอน เหมาะเมื่อรู้อยู่แล้วว่าต้องการ stack แบบไหน ดู [templates.md](./templates.md)
2. **ให้ AI agent วางแผน** ไปที่ `/builder` แท็บ "Ask the AI agent" แล้วพิมพ์อธิบายแอปเป็นภาษาไทยหรืออังกฤษ เช่น "แดชบอร์ดยอดขายพร้อม CI และเทสต์" agent จะเลือกเทมเพลตที่ใกล้ที่สุด เลือก add-on และอาจเพิ่มขั้นตอนพิเศษ ถ้าเซิร์ฟเวอร์ไม่มี API key ก็ยังใช้ได้ผ่าน offline planner ดู [ai-agent.md](./ai-agent.md)
3. **เปิดลิงก์ที่มีคนแชร์มา** ลิงก์รูปแบบ `/builder#s=...` จะพาไปยังขั้น Review พร้อมสแต็กเดิมทุกประการ ดู [sharing.md](./sharing.md)

## ลองครั้งแรก (แนะนำ)

1. เปิดหน้าแรก กด **Ask the AI agent** หรือ **Browse templates**
2. ในตัวสร้าง (builder) ขั้น **Start** เลือก "Pick a template" แล้วเลือก *Next.js Analytics Dashboard*
3. ขั้น **Configure** ตั้งชื่อโปรเจกต์ เลือกเวอร์ชัน Node (LTS/24/22/20) ตัวจัดการแพ็กเกจ (npm/pnpm/yarn) และ add-on เช่น Testing หรือ Docker สังเกตว่าตัวสรุปสแต็ก (current stack) ด้านบนเปลี่ยนตาม
4. ขั้น **Review & reorder** อ่านแต่ละขั้น ลากเพื่อสลับลำดับ ลบขั้นที่ไม่ต้องการ หรือเพิ่มขั้นตอนของคุณเอง
5. ขั้น **Export** คัดลอกคำสั่งทั้งหมด หรือดาวน์โหลด `setup.sh` (macOS/Linux/WSL) / `setup.ps1` (Windows) / starter `.zip`
6. เปิดสคริปต์ อ่านทุกบรรทัด แล้วรัน `bash setup.sh` ในโฟลเดอร์ว่าง ขั้นที่เป็น dev server หรือ publish จะถูกคอมเมนต์ไว้โดยตั้งใจ ให้รันเองในเทอร์มินัลแยก

## สิ่งที่ควรมีบนเครื่อง

- **Node.js** ผ่าน nvm (macOS/Linux) หรือ nvm-windows สำหรับเทมเพลตฝั่ง JavaScript ขั้นติดตั้ง nvm เป็นขั้น `requires: nvm` สคริปต์จะข้ามพร้อมคำเตือนถ้าไม่พบ nvm
- **Python 3.11–3.13** หรือ **uv** สำหรับเทมเพลตฝั่ง Python
- Git และเทอร์มินัล (bash/zsh หรือ PowerShell)

## คำแนะนำ

- เริ่มจากค่าเริ่มต้นของเทมเพลตก่อน แล้วค่อยเพิ่ม add-on ทีละตัว เพื่อให้รู้ว่าแต่ละตัวเพิ่มขั้นตอนอะไร
- อ่านคอลัมน์ "Expected result" และรัน "Verify" หลังแต่ละขั้น จะจับปัญหาได้เร็วกว่ารันรวดเดียวแล้วค่อยหาว่าพังตรงไหน
- เก็บลิงก์แชร์ไว้ในโน้ตของโปรเจกต์ เพื่อสร้างสแต็กเดิมซ้ำได้ภายหลัง
