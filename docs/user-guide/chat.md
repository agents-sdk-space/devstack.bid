# Chat (User Chat)

หน้า [`/chat`](https://devstack.bid/chat) คือแชต AI ฟรีของเรา ถามได้ทุกเรื่องทั้งภาษาไทยและอังกฤษ ให้ช่วยเขียนโค้ด หรือพิมพ์คำบรรยายแล้วให้มันวาดภาพให้ ไม่ต้องมี key การเข้าสู่ระบบเป็นทางเลือก ถ้ายังไม่เข้าสู่ระบบ ประวัติแชตอยู่กับเบราว์เซอร์นี้

## เข้าสู่ระบบ

ประกาศอย่างเป็นทางการ 14 ตุลาคม 2026: ปุ่ม **เข้าสู่ระบบด้วย Cursor** เปิดบน [devstack.bid](https://devstack.bid/login) แล้ว กดเข้าสู่ระบบ ยืนยันแอป DevStack ใน Cursor แล้วประวัติแชตจะอยู่กับบัญชีนั้น คำถามที่พิมพ์ในช่องแชตยังตอบโดยโมเดลที่เลือกบนแถบเหนือช่องพิมพ์ การตรวจปลายทางกับเว็บจริงในวันเดียวกันผ่านแล้ว ทั้งภาษาอังกฤษและภาษาไทยไปถึง Cursor ด้วย callback `https://devstack.bid/api/auth/cursor/callback` และไม่เจอข้อความ `redirect_uri is not allowed`

ปุ่ม **เข้าสู่ระบบ** อยู่ที่หัวเว็บทุกหน้า และบนแถบประวัติแชต หน้า [`/login`](https://devstack.bid/login) มีสี่วิธี

| วิธี | ใช้ทำอะไร | สิ่งที่เซิร์ฟเวอร์ต้องมี |
|---|---|---|
| Cursor | ติดตั้งแอป Origin ของ DevStack แล้วเข้าสู่ระบบด้วยผู้ใช้ที่กดติดตั้ง ใบเสร็จติดตั้งถูกตรวจลายเซ็น ไม่ถูกเก็บ | `CURSOR_APP_ID` และ callback `{origin}/api/auth/cursor/callback` |
| Google | เข้าสู่ระบบด้วยบัญชี Google (openid, email, profile) ไม่เก็บ access token | `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, callback `{origin}/api/auth/google/callback` |
| GitHub | เข้าสู่ระบบและส่งโค้ดขึ้น repo ได้ ขอ `read:user`, `user:email`, `repo` token ถูกเข้ารหัสลง D1 | `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, callback `{origin}/api/auth/github/callback` |
| บัญชี DevStack | อีเมลกับรหัสผ่านอย่างน้อย 10 ตัวอักษร เก็บเฉพาะแฮช PBKDF2 | `CHAT_COOKIE_SECRET` และ D1 |

- อีเมลเดียวกันบนคนละวิธียังเป็นคนละบัญชี ไม่มีการผูกอัตโนมัติ
- แชตที่สร้างไว้บนเบราว์เซอร์นี้ก่อนเข้าสู่ระบบครั้งแรกจะย้ายไปอยู่กับบัญชีนั้น ถ้าแถวนั้นยังไม่เคยเข้าสู่ระบบ
- เปิดเบราว์เซอร์อื่นแล้วเข้าสู่ระบบบัญชีเดิม จะเห็นประวัติชุดเดียวกัน
- ออกจากระบบจะลบ token GitHub ที่เข้ารหัสไว้ รหัสผ่านยังอยู่เพื่อเข้าใหม่ แชตยังอยู่ที่บัญชี
- ถ้ายังไม่ตั้งค่าของวิธีนั้น หน้าเข้าสู่ระบบจะบอกว่าวิธีนั้นยังไม่เปิด บน production callback ใช้ origin `https://devstack.bid`

## ส่งโค้ดขึ้น GitHub

เมื่อคำตอบมีบล็อกโค้ด จะมีปุ่ม **ส่งขึ้น GitHub** (หรือลิงก์ให้เข้าสู่ระบบก่อน) เลือก repo, พาธ, สาขา แล้ว commit ไฟล์เดียวผ่าน GitHub API เซิร์ฟเวอร์ไม่รันโค้ดนั้น ถ้าอยากกำหนดพาธจากในคำตอบ ให้ขึ้นบรรทัดแรกในบล็อกด้วย `// file: src/app.ts` หรือ `# file: src/hello.py`

## โควตาฟรี

- **20 ข้อความ และ 5 ภาพ ต่อวัน** ต่อเบราว์เซอร์ (นับจาก cookie `nvx_chat_uid`) การสร้างภาพไม่กินโควตาข้อความ
- รีเซ็ตตอน **เที่ยงคืนเวลาไทย**
- มีเพดานต่อเครือข่าย (IP) = 3 เท่าของโควตาต่อคน และเพดานรวมทั้งเว็บต่อวัน เพื่อให้เราเปิดบริการฟรีต่อไปได้
- ส่งได้ไม่เกิน 4 ข้อความต่อนาที

ตัวเลขที่เหลืออยู่แสดงใต้ช่องพิมพ์ เมื่อใช้ครบ เราจะแสดงข้อความแจ้งเป็นไทยและอังกฤษพร้อมเวลารีเซ็ต

## ไฟล์แนบ

ปุ่มคลิปหนีบกระดาษยังกดไม่ได้ เพราะเรายังไม่เปิดที่เก็บไฟล์ (R2) ฝั่งเซิร์ฟเวอร์รองรับไฟล์ไม่เกิน 10 MB ไว้แล้ว เมื่อเปิด R2 ปุ่มนี้จะใช้ได้ทันที

## ประวัติและความเป็นส่วนตัว

แชตของคุณเก็บใน D1 ถ้ายังไม่เข้าสู่ระบบ มันผูกกับ cookie ของเบราว์เซอร์นี้ ถ้าเข้าสู่ระบบด้วย GitHub มันผูกกับบัญชีนั้นแทน เปิดดูย้อนหลังได้จากแถบซ้าย (มือถือกดปุ่ม "ประวัติแชต") ลบได้ทีละแชต อย่าพิมพ์รหัสผ่านหรือข้อมูลส่วนตัวที่อ่อนไหวลงในแชต เราไม่เก็บ GitHub token แบบอ่านได้: ที่อยู่ในฐานข้อมูลเป็น ciphertext AES-GCM
