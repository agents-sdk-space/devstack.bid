# Chat (User Chat)

หน้า [`/chat`](https://devstack.bid/chat) คือแชต AI ฟรีของเรา ถามได้ทุกเรื่องทั้งภาษาไทยและอังกฤษ ให้ช่วยเขียนโค้ด หรือพิมพ์คำบรรยายแล้วให้มันวาดภาพให้ ไม่ต้องสมัครสมาชิก ไม่ต้องมี key

## เลือกโมเดล

แถบเหนือช่องพิมพ์มีโมเดลให้เลือก เราจำตัวเลือกล่าสุดไว้ในเบราว์เซอร์ของคุณ (ยกเว้นโหมดภาพ)

| ปุ่ม | โมเดล | เหมาะกับ |
|---|---|---|
| ทั่วไป · Gemma 4 (CF) | `@cf/google/gemma-4-26b-a4b-it` | คำถามทั่วไป สรุป อธิบาย |
| ภาษาไทย · SEA-LION (CF) | `@cf/aisingapore/gemma-sea-lion-v4-27b-it` | ภาษาไทยที่เป็นธรรมชาติ บริบทเอเชียตะวันออกเฉียงใต้ |
| โค้ด · Qwen Coder (CF) | `@cf/qwen/qwen2.5-coder-32b-instruct` | เขียน/อธิบาย/แก้โค้ด |
| เก่งขึ้น · DeepSeek V3 (HF) | `deepseek-ai/DeepSeek-V3` ผ่าน Hugging Face | งานที่ต้องคิดหลายขั้น |
| สร้างภาพ · FLUX (CF) | `@cf/black-forest-labs/flux-1-schnell` | ภาพจากคำบรรยาย (1024px, 4 steps) |

CF = Cloudflare Workers AI, HF = Hugging Face ถ้าโมเดลที่เลือกล่มหรือตอบไม่ได้ เราสลับไปอีกค่ายให้อัตโนมัติ (Workers AI → DeepSeek V3, DeepSeek V3 → Gemma 4) และบันทึกไว้ว่าข้อความนั้นตอบด้วยโมเดลไหน

## โควตาฟรี

- **20 ข้อความ และ 5 ภาพ ต่อวัน** ต่อเบราว์เซอร์ (นับจาก cookie `nvx_chat_uid`) การสร้างภาพไม่กินโควตาข้อความ
- รีเซ็ตตอน **เที่ยงคืนเวลาไทย**
- มีเพดานต่อเครือข่าย (IP) = 3 เท่าของโควตาต่อคน และเพดานรวมทั้งเว็บต่อวัน เพื่อให้เราเปิดบริการฟรีต่อไปได้
- ส่งได้ไม่เกิน 4 ข้อความต่อนาที

ตัวเลขที่เหลืออยู่แสดงใต้ช่องพิมพ์ เมื่อใช้ครบ เราจะแสดงข้อความแจ้งเป็นไทยและอังกฤษพร้อมเวลารีเซ็ต

## ไฟล์แนบ

ปุ่มคลิปหนีบกระดาษยังกดไม่ได้ เพราะเรายังไม่เปิดที่เก็บไฟล์ (R2) ฝั่งเซิร์ฟเวอร์รองรับไฟล์ไม่เกิน 10 MB ไว้แล้ว เมื่อเปิด R2 ปุ่มนี้จะใช้ได้ทันที

## ประวัติและความเป็นส่วนตัว

แชตของคุณเก็บใน D1 ผูกกับ cookie ของเบราว์เซอร์นี้ เปิดดูย้อนหลังได้จากแถบซ้าย (มือถือกดปุ่ม "ประวัติแชต") ลบได้ทีละแชต ถ้าลบ cookie เราจะผูกแชตเดิมกับคุณไม่ได้อีก อย่าพิมพ์รหัสผ่านหรือข้อมูลส่วนตัวที่อ่อนไหวลงในแชต
