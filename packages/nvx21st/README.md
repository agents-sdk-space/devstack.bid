# nvx21st

The command-line tool for devstack.bid templates. The full manual is in [nvx21st.1.md](./nvx21st.1.md), or run `nvx21st man`.

```
npm i -g ./packages/nvx21st      # from a devstack.bid checkout
nvx21st list
nvx21st logo github --save public/logos
nvx21st theme ./my-theme.css
```

MIT. Zero dependencies. Needs Node.js 20 or newer.
